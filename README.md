## <img src="https://img.icons8.com/color/48/lightning-bolt.png" width="35" align="top"/> What is BytePi4?

**BytePi4** is a high-performance, dynamic runtime engine tailored for running heavy AI workloads—specifically customized for **PCB Defect Detection**—on resource-constrained ARM devices such as the Raspberry Pi 4. It intelligently balances performance and thermal constraints using real-time telemetry!

> **Why BytePi4?** Edge devices easily overheat and throttle when running continuous neural networks for industrial inspections. BytePi4 solves this by automatically tuning resolution, frame skipping, and CPU load on the fly, ensuring your PCB defect models run reliably 24/7!

## <img src="https://img.icons8.com/color/48/star.png" width="35" align="top"/> Key Features

| Feature | Description |
| :--- | :--- |
| <img src="https://img.icons8.com/color/48/search.png" width="25" align="center"/> **PCB Defect Inference** | Seamlessly runs custom `best_int8.tflite` PCB defect detection models via Ultralytics. |
| <img src="https://img.icons8.com/color/48/thermometer.png" width="25" align="center"/> **Thermal & Resource Management** | Automatically throttles inference if CPU/Memory usage or Temperature reaches critical thresholds. |
| <img src="https://img.icons8.com/color/48/camera.png" width="25" align="center"/> **Dynamic Resolution** | Auto-scales camera feed resolution (from 640x480 down to 320x240) based on system stress. |
| <img src="https://img.icons8.com/color/48/fast-forward.png" width="25" align="center"/> **Adaptive Frame Skipping** | Drops frames intelligently to maintain system stability during heavy industrial load spikes. |
| <img src="https://img.icons8.com/color/48/combo-chart.png" width="25" align="center"/> **Prometheus Integration** | Built-in Prometheus exporter for live dashboards monitoring FPS, latency, memory, and temperature. |

## <img src="https://img.icons8.com/color/48/rocket.png" width="35" align="top"/> Quick Start

### 1. Clone & Setup
```bash
git clone https://github.com/SanjayG-xls/BytePi4.git
cd BytePi4
pip install -r requirements.txt
bash create_structure.sh
```

### 2. Run the Engine
Fire up the main runtime script:
```bash
python scripts/run_runtime.py
```

### 3. Run PCB Defect Inference Test
Test the camera and YOLO optimization explicitly:
```bash
python test_yolo.py
```

## <img src="https://img.icons8.com/color/48/combo-chart.png" width="35" align="top"/> Dashboard & Monitoring

BytePi4 exposes metrics via Prometheus. Check `configs/optimization.yaml` to adjust thresholds!

- **CPU & Mem**: Low < 40%, High > 75%, Critical > 90%
- **Temperature**: Warning > 70°C, Critical > 80°C
- **Resolution Levels**: `[640, 480]`, `[512, 384]`, `[480, 360]`, `[320, 240]`
